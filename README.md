# To-Do List Application

A simple graphical task management application developed using C++ and the BGI graphics library.

## Features
- Add new tasks.
- Display saved tasks.
- Store tasks in a text file.

## Technologies
- C++
- BGI Graphics Library (`graphics.h`)
- File Handling

## How to Run
1. Clone the repository.
2. Open `C-PROJE.cpp` in a BGI-compatible C++ development environment.
3. Configure the BGI graphics library.
4. Compile and run the project.

**Note:** The project currently uses the BGI directory `C:\TURBOC3\BGI`. This path may need to be adjusted.
